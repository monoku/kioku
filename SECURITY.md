# Security

[The threat model](docs/explanation/threat-model.md) says what Kioku defends
against, what it does not, and where the line is drawn.

To report a vulnerability, use **Report a vulnerability** on this repository's
Security tab, which keeps it private until a fix is out. Please do not open a
public issue. Say what an attacker can do, and the steps and the version
(`kioku --version`) that show it. Fixes go into the next release; the latest
release is the one supported.
